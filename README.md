# Reverse Proxy CDN

A lightweight reverse proxy + CDN simulator built to demonstrate caching strategies,
latency reduction, and reverse-proxy architecture.

## Status: 🚧 Work in progress

## Architecture
- **origin-server/** — simulated slow backend (artificial 200ms delay)
- **proxy-server/** — reverse proxy with Redis caching (in progress)
- **dashboard/** — React + Tailwind analytics dashboard (planned)
